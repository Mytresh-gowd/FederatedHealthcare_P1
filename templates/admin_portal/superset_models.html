Important model behaviour

A superset retains the trees from each selected version. This can preserve learning from different rounds or age groups, but it can also retain weak or incorrect trees. Evaluate the superset on a held-out test set before using it for clinical decisions. This application is a research prototype, not a diagnostic device.
